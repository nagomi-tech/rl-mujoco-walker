# 階段環境ベースライン（視覚なし）

## 概要

視覚情報（地形データ）なしで階段登りを学習したベースライン実験。
ロボットは固有感覚（関節角度・速度）のみで階段を検知し行動する。

## 環境パラメータ

| パラメータ | 値 |
|-----------|-----|
| 階段段数 | 8段 |
| 1段の高さ | 5cm |
| 1段の奥行き | 40cm（足長26cmに対して14cm余裕） |
| 階段開始X | 2.0m |
| 階段終了X | 5.2m |
| ゴールX | 6.2m |
| ゴール高さZ | 0.40m（最上段） |
| エピソード最大ステップ | 1000 |
| フレームスキップ | 4（実効dt = 0.02s） |

## 観測空間（35次元）

| 要素 | 次元 | 説明 |
|------|------|------|
| qpos[2:17] | 15 | 関節角度（z, 四元数, 各関節） |
| qvel[:16] | 16 | 関節速度 |
| dist_to_goal | 1 | ゴールまでの距離（正規化） |
| hand_flag | 1 | 腕接触フラグ |
| padding | 2 | 未使用（0固定） |

**地形情報は一切含まない。** ロボットは足が段差に当たって初めて段差を「感知」する。

## 報酬設計

| 報酬項目 | 値 |
|---------|-----|
| ゴール接近 | `progress * 50.0`（毎ステップ） |
| ゴール到達ボーナス | +200.0 |
| 交互腿上げボーナス | +2.0（左右交互に股関節屈曲 < -0.3rad のとき） |

ペナルティなし（転倒・腕接触・膝つき全てペナルティなし）。

## モデルアーキテクチャ

- アルゴリズム: PPO（Stable-Baselines3）
- ポリシー: MlpPolicy（256×256 hidden layers）
- 並列環境: SubprocVecEnv, n_envs=8
- VecNormalize: 観測・報酬の正規化あり

## 学習設定

- 学習率: 0.0003（デフォルト）
- n_steps: 2048
- batch_size: 64
- チャンクサイズ: 3M steps

## 結果

| チェックポイント | 最高エピソード報酬 | 最大ステップ数 |
|----------------|-----------------|-------------|
| 3M | 207.8 | 123 |
| 6M | 238.5 | 170 |
| 9M | 299.6 | 183 |
| 12M | **306.8** | **206** |
| 15M | 207.0 | 166 |
| 18M | 268.5 | 186 |

動画: `results/stairs_{3,6,9,12,15,18}m.mp4`
最良モデル: `models/stairs/ckpt_12m/best_model`

## 観察された挙動

- 3M: よろけながらも交互に足を前に出す（最初の改善）
- 6M〜12M: 3歩程度まで階段を登れるようになる
- 12Mがピーク。15M・18Mは若干後退（局所最適付近での揺らぎ）
- ゴール（全段登り切り）には未到達

## 限界

- ロボットに地形の視覚情報がないため、段差に当たってから反応する受動的な行動しか学習できない
- 予測的な腿上げ（段差が見えたら事前に足を上げる）は学習できない
- これが視覚なし手法の根本的な限界と判断し、次フェーズで地形観測を追加する
